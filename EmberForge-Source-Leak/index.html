Executive Summary

EmberForge Studios, a game development subsidiary, suffered a targeted intrusion on 30 January 2026 that resulted in the full exfiltration of unreleased source code for the upcoming title Neon Shadows. A lead artist was socially engineered into executing a malicious ISO file disguised as a project review archive, granting the attacker an initial foothold.

Within three hours, the attacker escalated to domain administrator privileges, moved laterally across all three network endpoints, stole the Active Directory credential database, and exfiltrated the entire game development directory to a MEGA cloud storage account under their control.

The attacker attempted to clear Windows event logs on the Domain Controller, but Sysmon telemetry had already been forwarded to Microsoft Sentinel — preserving a complete forensic record. The evidence chain is assessed as complete.

Attack Phase Analysis

PHASE 1 Initial Access — ISO Delivery & MotW Bypass T1204.002 ›

Lisa Martin received a file named to appeal directly to her role as Lead Artist — a project review archive. The file was delivered as an ISO disk image, specifically chosen to bypass Windows' Mark-of-the-Web protection. Files extracted from a mounted ISO do not inherit the MotW tag, allowing silent execution with no SmartScreen warning shown to the user.

The execution chain: explorer.exe > rundll32.exe > D:\review.dll,StartW

EmberForgeX_CL
| where EventCode_s == "1"
| where Computer contains "B9GHHO6"
| where CommandLine_s contains "review.dll"
| project UtcTime_s, User_s, Image_s, CommandLine_s, ParentImage_s
PHASE 2 Privilege Escalation — fodhelper UAC Bypass T1548.002 ›

The malware wrote update.exe into the registry key read by fodhelper.exe — a trusted Windows binary that auto-elevates without a UAC prompt. Setting the DelegateExecute value (even empty) triggers elevation. update.exe was spawned as NT AUTHORITY\SYSTEM without any user interaction.

EmberForgeX_CL
| where EventCode_s == "13"
| where TargetObject_s contains "ms-settings\shell\open\command"
| project UtcTime_s, Image_s, TargetObject_s, Details_s
PHASE 3 Credential Access — LSASS & NTDS.dit T1003.001 · T1003.003 ›

Two credential theft operations: LSASS dumped on the workstation using direct syscalls (bypassing EventCode 10 — no API monitoring triggered), and NTDS.dit extracted on the DC via VSS shadow copy. The NTDS.dit contains every domain password hash. Combined, all credentials in the environment are compromised.

EmberForgeX_CL
| where EventCode_s == "11"
| where TargetFilename_s has_any (".dmp", "lsass")
| project UtcTime_s, Computer, Image_s, TargetFilename_s
PHASE 4 Lateral Movement — Impacket Remote Execution T1021.002 · T1570 ›

Initial lateral movement via NTLM Pass-the-Hash failed (11 consecutive 4625 events, error 0x80090308). The attacker pivoted to Impacket — creating random 8-character Windows services (MzLblBFm, QjhJMWqS, pGJLIKnC) that execute commands, write output to C$\__output, and self-delete. First command on every new host: whoami.

EmberForgeX_CL
| where EventCode_s == "7045"
| extend ServiceName = extract("ServiceName'>([^<]+)", 1, Raw_s)
| extend ServiceFile = extract("ImagePath'>([^<]+)", 1, Raw_s)
| project TimeGenerated, Computer, ServiceName, ServiceFile
PHASE 5 Exfiltration — rclone to MEGA T1567.002 ›

C:\GameDev compressed via native PowerShell Compress-Archive cmdlet (no third-party tools), then uploaded to MEGA via rclone. Three attempts were made — the second exposed credentials in plaintext on the command line when the config file failed. Connection confirmed to bt5.api.mega.co.nz (66.203.125.15) on port 443.

EmberForgeX_CL
| where EventCode_s == "3"
| where Computer contains "16V3AU4"
| where Image_s contains "rclone"
| project UtcTime_s, DestinationIp_s, DestinationPort_s, DestinationHostname_s
PHASE 6 Persistence — Five Mechanisms T1053.005 · T1219 · T1136.002 ›

Five distinct persistence mechanisms were established: (1) Scheduled task WindowsUpdate running update.exe on startup and logon. (2) AnyDesk installed in silent mode with unattended access password set to SHA1("password"). (3) AnyDesk.lnk in Startup folder on Workstation and Server. (4) update.exe injected into spoolsv.exe (SYSTEM). (5) svc_backup Domain Admin account — survives full endpoint rebuild.

Recommendations

🔴 Immediate (0–4 hrs)

  • Delete svc_backup from Active Directory
  • Reset Administrator password — EmberForge2024! is exposed
  • Reset krbtgt TWICE (24 hrs apart)
  • Block *.cloud-endpoint.net at DNS and firewall
  • Report jwilson.vhr@proton.me to MEGA abuse team
  • Isolate all three endpoints from network

🟠 Short Term (4–24 hrs)

  • Remove update.exe, rclone.exe, AnyDesk from all hosts
  • Delete scheduled task WindowsUpdate
  • Remove AnyDesk.lnk from Startup folders
  • Remove firewall rule SMB (port 445 inbound)
  • Full domain password reset — NTDS.dit stolen
  • Delete lsass.dmp from C:\Windows\System32\

🛡️ Detection Rules

  • Alert: spoolsv.exe spawning cmd.exe or powershell.exe
  • Alert: certutil -urlcache with outbound HTTP
  • Alert: random 8-char service names (Impacket)
  • Alert: .dmp file created outside WerFault.exe
  • Alert: Sysmon service stopped (EventCode 7036)
  • Alert: ms-settings registry key modification

🔵 Long Term

  • Enable Credential Guard to protect LSASS
  • Deploy Protected Process Light for Sysmon
  • Implement LAPS for local admin passwords
  • Block ISO auto-mount or require prompt
  • Network segmentation — Workstation to DC
  • Phishing-resistant MFA across all accounts
